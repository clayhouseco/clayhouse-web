# Proyectos — inspiración Romano

**Una carpeta = un proyecto** en el carrusel de inspiración.

## Cómo agregar fotos

1. Crea una carpeta con nombre corto en minúsculas y guiones, por ejemplo:
   - `casa-nua-romano-rojo`
   - `casa-retiro-matizado`
2. Sube todas las fotos de ese proyecto dentro de esa carpeta (JPG o PNG).
3. El título en la web se genera del nombre de carpeta: `casa-nua-romano-rojo` → **Casa Nua Romano Rojo**.

## No mezclar

- No pongas fotos de distintos proyectos en la misma carpeta.
- Las fotos de **producto** (pieza, renders) van en `matizado/`, `matizado-oscuro/` o `natural/`, no aquí.
