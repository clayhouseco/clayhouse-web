## Archivos recomendados

| Archivo | Uso en la web |
|---------|----------------|
| `producto.jpg` | Foto principal del producto (galería) |
| `detalle-1.jpg`, `detalle-2.jpg` | Fotos extra en la galería |
| `dimensiones.jpg` | Diagrama técnico con medidas |
| `fachada.jpg` | Render o foto en obra / ambiente |

Cuando subas `producto.jpg` y los demás, avisa para enlazarlos en el catálogo (o actualiza `src/data/products.ts`).

Fotos generales retocadas: `public/images/Editadas/`
