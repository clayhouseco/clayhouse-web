# Logos de clientes

Coloque aquí los archivos de marca (SVG o PNG con fondo transparente, ~200–400 px de ancho).

En `src/data/clients.ts` (`brandClients` o `projectPartners`) asigne la ruta con `assetUrl`:

```ts
{ id: "starbucks", name: "Starbucks", logo: assetUrl("/images/clientes/starbucks.svg") },
```
