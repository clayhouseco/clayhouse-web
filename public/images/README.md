# Imágenes — Clay House

Sube aquí tus archivos. Nombres recomendados:

## Logo (también puede ir en `/public/`)

- `public/logo.png` o `public/logo.svg` — logo principal del menú

## Hero (home)

- `public/images/hero/hero.jpg` — imagen o poster del video principal
- `public/images/hero/redescubre.jpg` — bloque "redescubre el ladrillo"
- `public/images/hero/horno.jpg` — bloque horno túnel

## Productos (una foto principal por producto)

Guarda en `public/images/products/` con el **slug** del producto:

| Archivo | Producto |
|---------|----------|
| `ladrillo-f-pv.jpg` | Ladrillo F-PV |
| `ladrillo-macizo.jpg` | Ladrillo macizo |
| `piezas-especiales.jpg` | Piezas especiales |
| `ladrillo-toscano-claro.jpg` | Toscano claro |
| `ladrillo-toscano-oscuro.jpg` | Toscano oscuro |
| `ladrillo-f-pv-rayado-vertical.jpg` | Rayado vertical |
| `piso-rustico-barro.jpg` | Piso rústico |

Formatos: `.jpg`, `.webp` o `.png`

Puedes añadir más fotos por producto en `public/images/products/{slug}/02.jpg`, etc. (avísame y las enlazo en la galería).
